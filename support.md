# Support

Write to **sassimaterasas@gmail.com**, in English or Italian. We aim to answer within one business day
(Monday to Friday, 9:00-18:00 Central European Time).

To help us answer quickly, please include:
- the address of your Jira site (for example `your-company.atlassian.net`);
- a screenshot of the app page in Jira (*Settings > Apps > On-Prem Git & SVN*), including **Needs
  attention** if it shows anything;
- for GitLab: the response shown in the system hook's **Recent events**;
- for Subversion: the output of the `status` command of the connector hook (see the
  [user guide](user-guide.md#troubleshooting-subversion-deliveries)).

Please do not send the secret token or other passwords.

Security issues can be reported privately to the same address.
